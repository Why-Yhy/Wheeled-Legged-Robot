# 平面五杆轮腿机构 · 运动学知识点与坑



## 0. 符号与建模约定

![](C:\Users\yyh\Pictures\Screenshots\屏幕截图 2026-11-02 092717.png)

- 平面机构：基座两固定铰 O(0,0)、D(l5,0)；左臂 l1 与水平线夹角 **α**，右臂 l4 与水平线夹角 **β**；肘关节 A、C；连杆 l2（A→B）、l3（C→B）；**B(x,y) 为末端**（轮心）。
- θ1、θ2：连杆 l2、l3 相对 x 轴正向的方向角，**逆时针为正**。
- 约定全局统一：角度一律**弧度**，长度一律同一单位（mm），坐标系右手系。

## 1. 三个基本功（贯穿正逆解）

**① 极坐标 → 直角坐标**（P 相对 Q 距 r、方向角 θ）：

$$\huge\pmb{\boxed{x_P = x_Q + r\cos\theta,\qquad y_P = y_Q + r\sin\theta}}$$

**② 万能半角代换**：任何「一次正余弦方程」$a\cos\theta + b\sin\theta = c$ 都可化为二次方程：

$$\huge\pmb{\boxed{z = \tan\frac{\theta}{2}},\qquad \cos\theta = \frac{1-z^2}{1+z^2},\qquad \sin\theta = \frac{2z}{1+z^2}}$$

$$\huge\pmb{(a+c)\,z^2 - 2b\,z + (c-a) = 0}$$

**③ 反代回角度，编程一律用 atan2**：

$$\huge\pmb{\boxed{\theta = 2\,\mathrm{atan2}\!\left(b \pm \sqrt{a^2+b^2-c^2},\; a+c\right)}}$$

atan2 同时解决**分母为零**与**象限丢失**两个问题，普通 arctan 两个都会出事。

## 2. 正运动学：已知 α、β 求 B(x, y)

**路线**：肘点坐标 → 两条路各写一次 B → 消 θ2 → 半角代换解 θ1 → 回代 B。

**① 肘点**：

$$\huge\pmb{\boxed{x_a = l_1\cos\alpha,\quad y_a = l_1\sin\alpha}}\qquad \huge\pmb{\boxed{x_c = l_5+l_4\cos\beta,\quad y_c = l_4\sin\beta}}$$

**② 两路写 B**：

$$\huge\pmb{x = x_a + l_2\cos\theta_1,\qquad y = y_a + l_2\sin\theta_1}$$

$$\huge\pmb{x = x_c + l_3\cos\theta_2,\qquad y = y_c + l_3\sin\theta_2}$$

**③ 消 θ2**（B 到 C 距离恒为 l3，平方相加）得一次正余弦方程

$$\huge\pmb{a\cos\theta_1 + b\sin\theta_1 = c}$$

$$\huge\pmb{\boxed{a = 2(x_a-x_c)\,l_2,\qquad b = 2(y_a-y_c)\,l_2,\qquad c = l_3^2 - l_2^2 - l_{AC}^2}}$$

（$l_{AC}$ 为 A、C 间距。）

**④ 解 θ1 并回代**：

$$\huge\pmb{\boxed{\theta_1 = 2\arctan\frac{b \pm \sqrt{a^2+b^2-c^2}}{a+c}}}$$

$$\huge\pmb{\boxed{x = l_1\cos\alpha + l_2\cos\theta_1,\qquad y = l_1\sin\alpha + l_2\sin\theta_1}}$$

**要点**：给定 (α, β) 时 θ1 只有 ± 两支，对应肘部「撑开 / 内折」一对镜像形态，由装配窗口取唯一支——正解**没有多解爆炸**，是一条干净映射。

## 3. 逆运动学：已知 B(x, y) 求 α、β

**路线**：把含 α 项留左边、θ1 项挪右边 → 平方相加消 θ1 → 半角代换 → 求根。β 侧完全对称（原点换成 D、l1→l4、l2→l3）。

**① 对 α 的一次正余弦方程**：

$$\huge\pmb{2x l_1\cos\alpha + 2y l_1\sin\alpha = x^2 + y^2 + l_1^2 - l_2^2}$$

$$\huge\pmb{\boxed{a = 2x\,l_1,\qquad b = 2y\,l_1,\qquad c = x^2 + y^2 + l_1^2 - l_2^2}}$$

**② 对 β**：

$$\huge\pmb{\boxed{d = 2(x-l_5)\,l_4,\qquad e = 2y\,l_4,\qquad f = (x-l_5)^2 + y^2 + l_4^2 - l_3^2}}$$

**③ 逆解核心公式**：

$$\huge\pmb{\boxed{\alpha = 2\arctan\frac{b \pm \sqrt{a^2+b^2-c^2}}{a+c},\qquad \beta = 2\arctan\frac{e \pm \sqrt{d^2+e^2-f^2}}{d+f}}}$$

**要点**：α、β 各带 ±，**两两组合共 4 组解**；α 的两支关于 OB 镜像、β 的两支关于 DB 镜像。逆解是「多对一」，必须靠区间判断挑回装配允许的那一组。

## 4. 可达工作空间

$$\huge\pmb{\boxed{a^2+b^2-c^2 \ge 0 \iff \bigl|l_1-l_2\bigr| \le \sqrt{x^2+y^2} \le l_1+l_2}}$$

几何含义：B 到 O 的距离必须落在左臂两杆能勾到的**圆环**内；右臂对 D 同理。**两个圆环的交集**才是整机可达域。判别式为负 = 目标点根本到不了。

## 5. 挑支与取值：通用三层法

任何 `2*atan2(...)` 出来的角，挑支前按三层各管一件事处理：

1. **atan2 管象限**：值域 (−π, π]，θ = 2·atan2 原始值域可到 (−2π, 2π]，天然出负角；
2. **mod 管统一刻度**：`mod(θ, 2π)` 把所有候选拉到 [0, 2π) 同一把尺子；
3. **区间管装配**：每个关节的合法窗口**由自己这台机器的装配定**，逐一确认。

通用流程（伪代码）：

```
θ1, θ2 ← 两支 2*atan2(...)
θ1 ← mod(θ1, 2π);  θ2 ← mod(θ2, 2π)
if θ1 ∈ 装配窗口 then θ ← θ1 else θ ← θ2   % 两支互为镜像，必一进一出，查一次就够
```

**「比较 π/2」只是窗口的一种特例**：窗口 [0°, 90°) 时门槛写成 `< pi/2`；窗口 [90°, 180°] 时门槛变成 `>= pi/2`。**左右关节的窗口常常方向相反**（一臂朝上装、一臂镜像装），不等号逐个对着实机确认，绝不能复用。

## 6. 关节角 → 电机指令：减速比与零位

$$\huge\pmb{\boxed{\theta_{motor} = i \cdot \theta_{joint}}}$$

i 为减速比（输出轴转 1 圈，电机轴转 i 圈）。运动学输出的是**输出连杆的关节角**，而 MIT 模式电机的目标位置/编码器读数的单位是**电机自己轴**的转角，中间隔着减速器，**不乘 i 就整体缩 i 倍**。

完整映射：

$$\huge\pmb{\boxed{q_{cmd} = q_{offset} \pm i\cdot\theta_{joint}}}$$

- **q_offset**：关节处于建模零位时的电机读数，**逐台标定**，不是理论值；
- **± 号**：由电机安装朝向决定——同侧前后镜像安装的两台电机，一个取 + 一个取 −；
- **方向约定**：机构建模（如「逆时针为正」）、电机正方向、轨迹绘图三处必须同一套，任何一处反号就只有个别轴反向动。

## 7. 正逆解在整机里的用途

- **正解 = 反馈侧**：编码器读关节角 → 正解 → 当前足端位置，进状态估计与控制闭环；
- **逆解 = 前馈侧**：期望足端轨迹 → 逆解 → 关节角 → 减速比映射 → 电机指令；
- **VMC 主链**：正解(当前足端) → 位置误差 → PID → 期望虚拟力 → **雅可比** → 各关节力矩；
- 雅可比矩阵 J 联系末端速度与关节速度（$\dot{x} = J\dot{q}$），也映射力：$\tau = J^{\mathrm T}F$，是下一模块的核心工具。

## 8. 可能的坑 · 速查表

| # | 坑 | 症状 | 根源 | 对策 |
|---|---|---|---|---|
| 1 | 挑支不等号方向抄反 | 机构变镜像，腿折向装不出的方向 | 左右关节装配窗口本就相反 | 每关节独立确认窗口；调试期枚举全部解画图 |
| 2 | 用 atan 不用 atan2 | 分母 a+c=0 出 inf/NaN，象限丢失 | arctan 值域只有一支 | 一律 `2*atan2(分子, 分母)` |
| 3 | C++ fmod 保留负号 | 归一化失效，负角混进区间比较 | `fmod(−30°,360°)=−30°`，不是 330° | 结果为负再 +2π；或用 MATLAB mod 语义自己包一层 |
| 4 | 目标点出了可达域 | sqrt 里负数 → NaN，姿态瞬间抽风 | 判别式 a²+b²−c² < 0 | 下发前先按圆环交集裁剪/夹边界 |
| 5 | 忘乘减速比 | 腿的动作整体缩小 i 倍且不报错 | 电机单位是转子转数≠关节角 | 映射层统一 `i*θ_joint`，换电机型号先改 i |
| 6 | 零位没标定 | 所有轨迹整体偏一个固定角度 | q_offset 是逐台实测量 | 标定量入配置，别写死理论值 |
| 7 | 正方向三处不统一 | 个别轴反向走、其余正常 | 建模/电机/绘图各用各的约定 | 一套约定写进注释，逐轴点动验证 |
| 8 | 仿真实机参数不同步 | 动画对、实机不对 | 幅值/周期/偏置两套数 | 同一组参数常量两边共用 |
| 9 | 角度弧度混用 | 轨迹周期荒谬变形 | sin 收弧度，人写度数 | 全链路弧度，只在人机边界换算 |
| 10 | 相邻帧跳支 | 轨迹平滑但腿突然弹一下 | 两支在边界附近来回切换 | 取「离上一帧最近」的解，加切换滞回 |
