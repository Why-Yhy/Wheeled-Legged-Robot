## 约定

机构图：O 为原点、x 轴水平向右；左臂 l1（关节角 α）、右臂 l4（关节角 β，起点在 D=(l5, 0)）；A、C 是两个肘关节，B(x, y) 是轮子中心。l2、l3 是两根连杆，θ1、θ2 是它们的方向角。实机杆长（代码里）：L1=150、L2=250、L3=250、L4=150、L5=108（单位 mm）。

通用小工具——极坐标转直角坐标：P 相对 Q 距离 r、方向角 θ，则

$$\huge\pmb{x_p = x_q + r\cos\theta,\qquad y_p = y_q + r\sin\theta}$$

（板书 yp 一行写成 xq+r·sinθ 是笔误，应为 yq。）

## 一、运动学正解：已知 α、β 求 B(x, y)

![机构图+极坐标](img/01_正解_极坐标转换_0634.png)

### 1. 从两条路各写一次 B 点

先把 A、C 用 α、β 直接算出来（就是极坐标小工具用一遍）：

$$\huge\pmb{x_a = l_1\cos\alpha,\qquad y_a = l_1\sin\alpha}$$

$$\huge\pmb{x_c = l_5 + l_4\cos\beta,\qquad y_c = l_4\sin\beta}$$

再沿左路（过 A，杆 l2，方向角 θ1）和右路（过 C，杆 l3，方向角 θ2）各写一次 B：

$$\huge\pmb{x = x_a + l_2\cos\theta_1,\qquad y = y_a + l_2\sin\theta_1}$$

$$\huge\pmb{x = x_c + l_3\cos\theta_2,\qquad y = y_c + l_3\sin\theta_2}$$

未知数只剩 θ1、θ2，目标是**消掉 θ2 解出 θ1**。

### 2. 消元：把 θ2 藏进距离里

右路移项平方相加，θ2 被 cos²+sin²=1 消掉（B 到 C 距离恒为 l3）：

$$\huge\pmb{(x - x_c)^2 + (y - y_c)^2 = l_3^2}$$

把左路 x、y 代入并展开，合并常数项后得到**一次正弦余弦方程**：

$$\huge\pmb{a\cos\theta_1 + b\sin\theta_1 = c}$$

$$\huge\pmb{a = 2(x_a-x_c)\,l_2,\qquad b = 2(y_a-y_c)\,l_2,\qquad c = l_3^2 - l_2^2 - l_{AC}^2}$$

其中 $l_{AC}$ 是 A、C 两点距离。

### 3. 万能半角代换

$$\huge\pmb{z = \tan\frac{\theta_1}{2},\qquad \cos\theta_1 = \frac{1-z^2}{1+z^2},\qquad \sin\theta_1 = \frac{2z}{1+z^2}}$$

代入乘开，化成一元二次方程：

$$\huge\pmb{(a+c)\,z^2 - 2b\,z + (c-a) = 0}$$

### 4. 求根公式 → θ1

$$\huge\pmb{\theta_1 = 2\arctan\frac{b \pm \sqrt{a^2+b^2-c^2}}{a+c}}$$

### 5. 回代出 B

$$\huge\pmb{x = l_1\cos\alpha + l_2\cos\theta_1,\qquad y = l_1\sin\alpha + l_2\sin\theta_1}$$

## 二、运动学逆解：已知 B(x, y) 求 α、β

![](C:\Users\yyh\Pictures\Screenshots\屏幕截图 2026-11-02 092717.png)

### 1. 起点还是那两条路

$$\huge\pmb{x = l_1\cos\alpha + l_2\cos\theta_1,\qquad y = l_1\sin\alpha + l_2\sin\theta_1}$$

这次 x、y 是**已知**，α 是**未知**。把含 α 的项留在左边、θ1 项挪右边，平方相加消掉 θ1（B 到 O 距离恒为 l2 的反用）：

$$\huge\pmb{(x - l_1\cos\alpha)^2 + (y - l_1\sin\alpha)^2 = l_2^2}$$

展开、用 cos²α+sin²α=1 合并，又是一个一次正余弦方程：

$$\huge\pmb{2x l_1\cos\alpha + 2y l_1\sin\alpha = x^2 + y^2 + l_1^2 - l_2^2}$$

### 2. 半角代换，套路同正解

$$\huge\pmb{z = \tan\frac{\alpha}{2},\qquad \cos\alpha = \frac{1-z^2}{1+z^2},\qquad \sin\alpha = \frac{2z}{1+z^2}}$$

代入得 $(a+c)z^2 - 2bz + (c-a) = 0$，求根后反代回 α。β 那侧完全对称：从 C 出发，把原点换成 D=(l5, 0)、l1 换成 l4、l2 换成 l3。

### 3. 逆解核心公式

$$\huge\pmb{\alpha = 2\arctan\frac{b \pm \sqrt{a^2+b^2-c^2}}{a+c},\qquad \beta = 2\arctan\frac{e \pm \sqrt{d^2+e^2-f^2}}{d+f}}$$

其中

$$\huge\pmb{a = 2x\,l_1,\qquad b = 2y\,l_1,\qquad c = x^2 + y^2 + l_1^2 - l_2^2}$$

$$\huge\pmb{d = 2(x-l_5)\,l_4,\qquad e = 2y\,l_4,\qquad f = (x-l_5)^2 + y^2 + l_4^2 - l_3^2}$$

α、β 各带一个 ±，**两两组合共 4 组解**——这就是逆解和正解最大的区别（正解给定 α、β 后主要挑 θ1 一支，逆解是 2×2）。

## 三、坑清单（时间戳 + 为什么要小心 + 怎么解决）

### 坑 1｜θ1 的取值范围：α 限定 [0, π/2]（≈15:00，板书总结页）

![正逆解对照页](img/11_正逆解对照_四组解_1500.png)

- **为什么要小心**：arctan 公式天然给出两支解（± 号），对应肘关节"撑开/折起"两种装配形态；数学上都成立，但实机连杆装死了一种，选错支解会算出机构穿模的姿态。板书在 θ1 后专门标了 θ1∈[0, π/2]。
- **怎么解决**：按物理装配定区间，代码里先 `mod(θ, 2π)` 归一化到 [0, 2π)，再和 π/2 比较挑支。MATLAB 实操（≈15:30，forwardKinematics.m 24–29 行）：

![正解代码_解的选择](img/13_正解代码_解的选择pi2_1530.png)

```matlab
theta1_1 = 2*atan2(b + sqrt(a^2+b^2-c^2), a + c);
theta1_2 = 2*atan2(b - sqrt(a^2+b^2-c^2), a + c);
theta1_1 = mod(theta1_1, 2*pi);   % 先归一化
theta1_2 = mod(theta1_2, 2*pi);
if theta1_1 < pi/2                % 再按区间挑
    theta1 = theta1_1;
else
    theta1 = theta1_2;
end
```

### 坑 3｜逆解的 4 组解与 α、β 判断方向**相反**（≈18:40，inverseKinematics.m）

![逆解代码_取值判断](img/17_逆解代码_取值判断_1840.png)

- **为什么要小心**：α 和 β 各两支，组合出 4 组 (α, β)；课上的选择逻辑是 **`if alpha1 >= pi/2 → 取 alpha1`，但 `if beta1 <= pi/2 → 取 beta1`**——两个关节的不等号方向是反的！因为左臂 α 实际工作在上半区、右臂 β 装法相反。照抄成同一个方向，机构直接变镜像，轮子朝天上拐。

### 坑 4｜根号里为负 = 目标点不可达（正逆解通用，≈10:37 / 14:30）

- **为什么要小心**：a²+b²−c² < 0 时公式没有实数解，对应两肘距离超出 l2+l3 或不足 |l2−l3|——出了可达工作空间。控制里如果直接 sqrt 会得到 NaN/复数，机器人当场抽风。
- **怎么解决**：下发目标点前先做边界检查（把期望 (x,y) 限在可达圈内），或算完发现判别式 <0 就夹回边界值；这是轨迹生成和运动学之间必须有的守门员。

### 坑 5｜atan2 而不是 atan（≈15:30 起所有代码）

- **为什么要小心**：公式写的是 2·arctan(分式)，但分母 a+c 可能为 0，普通 arctan 遇到还会丢象限。
- **怎么解决**：代码统一写 `2*atan2(b±sqrt(...), a+c)`，atan2 自动处理分母为零和象限问题——抄公式时别偷懒写成 atan。

### 坑 6｜减速比：关节角 ×8 才是电机角度（≈23:56，main.cpp calculateMotorTargets）

![减速比_电机映射](img/20_减速比_电机映射_2356.png)

- **为什么要小心**：运动学算出来的是**输出连杆的关节角**，但 MIT 电机（课上用 StackForce 6010，字幕标减速比 8）的编码器/目标位置单位是**电机自己轴的转数**。中间隔着一级减速器，差整整 8 倍——不乘减速比，你以为腿动了 45°，实际只掰了 5.6°，轨迹全错还不报错。
- **怎么解决**：在算机电机目标的函数里统一换算，课上代码结构：

```cpp
// 电机目标位置 = 零位偏移 ∓ 关节角 × 减速比
motorRightRear = POS_OF_RROQRDEE - (jointAngles.alphaRight ... ) * JOINT_GEAR_RATIO;
motorRightFront = POS_OF_RFOQRDEE - (jointAngles.betaRight ... ) * JOINT_GEAR_RATIO;
motorLeftRear  = POS_OF_LROQRDEE - (jointAngles.alphaLeft ... ) * JOINT_GEAR_RATIO;
motorLeftFront = POS_OF_LFOQRDEE - (jointAngles.betaLeft ... ) * JOINT_GEAR_RATIO;
```

  三个连带的点都要对上：①**正方向约定**——课上定"逆时针为正方向"（图中标红箭头），和电机自身正方向不一定一致，所以不同电机那行是加是减不一样；②**POS_OF_xxx 是零位标定值**，每台机器要自己标定后填；③**同侧前后两个电机驱动同一关节**，一个用 +α 一个用 −α（镜像安装），符号别抄反。换电机型号时 JOINT_GEAR_RATIO 必须跟着数据手册改。

## 附录：坑 1「归一化 + 按区间挑支」详解

### 1. 先搞清「区间」是谁定的

θ1 ∈ [0, π/2] 不是数学要求，是**装配要求**：肘关节实际只能朝前上方撑，l2 只会指向第一象限那一块。± 两支本来就是肘部「撑开 / 内折」关于 A、C 连线的镜像两形态，物理上只装得出一个，所以合法区间就是拿**这台机器的装配**当尺子。同理逆解里 α、β 的区间一高一低（α ≥ π/2、β ≤ π/2），就是左右两臂镜像安装——这正是坑 3 里不等号方向相反的根源。

### 2. 为什么非要先 mod(θ, 2π)

公式 θ1 = 2·arctan(z) 里 z = tan(θ1/2)。tan 的周期是 π，所以：

- 直接 arctan 出来的 θ1 只落在 (−π, π)；代码用更稳的 `2*atan2(b±√(a²+b²−c²), a+c)`，atan2 值域 (−π, π]，θ1 原始值域就是 **(−2π, 2π]，天然会出负角**。
- 「按区间挑」本质是判断**角落在圆上哪一段**，必须把所有候选拉到同一个 [0, 2π) 刻度上再比。反例：theta1_1 原始值 −30°、theta1_2 = 20°，直接比大小 −30° < 90° 好像该取它——可 −30° 实际是 330° 那个镜像位（肘朝下），实机没有这种装配。`mod(−30°, 360°) = 330°` 之后它被 π/2 门槛一眼刷掉，留下的 20° 才是真合法支。

   「和 π/2 比较挑支」说白了就是一道门槛题：**这个角过不过 90 度**。mod 之后两支各是一个 0~360° 的角度（比如 330° 和 20°），装配只允许 [0°, 90°) 那一段；`if theta1_1 < pi/2` 先让第一支过门槛，过了就用它，没过就说明它是镜像解——而**两支必然一进一出**（互为镜像），合法的只剩第二支，else 直接拿走，不用再查第二遍。

### 3. 代码逐行走一遍

```matlab
theta1_1 = 2*atan2(b + sqrt(a^2+b^2-c^2), a + c);  % 「+」支，原始值可能为负
theta1_2 = 2*atan2(b - sqrt(a^2+b^2-c^2), a + c);  % 「−」支
theta1_1 = mod(theta1_1, 2*pi);   % ① 统一刻度：全部拉到 [0, 2π)
theta1_2 = mod(theta1_2, 2*pi);
if theta1_1 < pi/2                % ② 落在物理装配窗口内就取它
    theta1 = theta1_1;
else                              % ③ 否则必是另一支（两支互为镜像，
    theta1 = theta1_2;            %    合法的那支只会剩一个）
end
```

### 4. 三个连带的注意点

- **MATLAB 的 mod 和 C 的 fmod 不一样**：`mod(−30, 360)` 给 330（非负），而 C/C++ 的 `std::fmod(−30.0, 360.0)` 给 **−30**，符号保留。往单片机（main.cpp）里搬这段时必须补一句「结果为负就 +2π」，否则归一化白做。
- **前提是判别式非负**：a²+b²−c² < 0 时 sqrt 出 NaN，比较全部失效——那是目标点出了可达工作空间（坑 4），要在挑支**之前**先拦下来。
- **边界 π/2 取不取得到无所谓**：除非装配恰好摆成正直位，两支不会正好压在边界上；真正要防的是把「谁 < π/2」抄反（对照坑 3：α 是 ≥、β 是 ≤）。

一句话记住：**atan2 管象限、mod 管统一刻度、区间判断管装配**——三层各干各的活，少一层都可能悄悄选到镜像解。
